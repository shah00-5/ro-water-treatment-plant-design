# RO Water Treatment Plant Design (3000 LPH Iron Removal + UF, 250 LPH RO)

Process flow design and equipment specification for an automatic drinking water treatment plant, prepared during my work as a Junior Engineer. Client details and pricing have been removed.

## Overview

The plant treats raw water containing iron and suspended solids, then purifies it to drinking quality. It can run in automatic or manual mode, 24 hours a day.

| Parameter | Value |
|---|---|
| Pre-treatment capacity | 3,000 LPH (iron removal + UF) |
| RO capacity | 250 LPH |
| TDS rejection | 95–99% |
| Treated water | Bacteria-free |

## Process Flow

Raw water reservoir (client scope) → Feed pumps (2 nos) → Multimedia filter → Iron removal filter → Activated carbon filter → 20" 0.45 µ cartridge filter → UF unit → Treated water tanks (5,000 L × 2) → High-pressure pump → RO unit (with antiscalant dosing and CIP) → UV lamp → SS304 treated water tank (1,000 L) → Drinking water line. Reject water goes to the waste drainage line.

## Main Components

| Unit | Specification |
|---|---|
| Feed pump | Horizontal multistage centrifugal, SS304, 0.75 kW, 7.2 m³/h, 38 m head |
| Multimedia filter | FRP vessel 1665, auto operation, anthracite + sand + gravel |
| Iron removal filter | FRP vessel 1665, auto operation, Katalox Light + gravel |
| Activated carbon filter | FRP vessel 1665, auto operation, coconut shell carbon + gravel |
| UF unit (optional) | Hollow fibre membrane, 0.01 micron, 1 m³/h, with backwash pump and CEB dosing |
| High-pressure pump | Vertical multistage centrifugal, SS304, 1.5 kW, 3.5 m³/h, 134 m head |
| RO unit | BW4040 membrane, SS304 housing and skid, control panel |
| Antiscalant dosing | 100 L tank, 5 L/h solenoid dosing pump |
